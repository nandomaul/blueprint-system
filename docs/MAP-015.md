# MAP-015 — Akun, share proyek dan navigasi

## Pasang di Mac

Simpan `blueprint-map-015-patch.cjs` di Downloads. Terminal VS Code:

```bash
(
  set -e
  cd "$HOME/Desktop/0. Canvas UI-UX"
  node "$HOME/Downloads/blueprint-map-015-patch.cjs" --stop-dev
  npm ci --include=dev --bin-links=true
  npm run build
  pbcopy < supabase/manual/blueprint-shared-MAP-015.sql
  open 'https://supabase.com/dashboard/project/qjmwxezxtsuikywqoajj/sql/new'
)
```

SQL sudah di clipboard. Pada **Supabase → SQL Editor → New query**, paste lalu **Run**. Isinya harus diawali `-- MAP-015`, bukan `#!/usr/bin/env node`. Jalankan seluruh file; transaksi gagal tidak boleh diteruskan dengan potongan SQL. Tidak reset/drop proyek, gambar, chat atau History. Dapat dijalankan ulang.

Kemudian:

```bash
cd "$HOME/Desktop/0. Canvas UI-UX"
npm run dev -- --open '/'
```

Installer memeriksa baseline MAP-011/012/013/014 dan alias `deploy: npm run build`. Berhenti tanpa menulis jika ada source tidak dikenali. Jangan memaksa overwrite. Flag `--stop-dev` hanya menghentikan Vite port5174 yang terbukti berasal dari folder ini. Backup/rollback source tercetak ke Terminal, di luar folder proyek dalam `~/Desktop/blueprint-checkpoints/`. Jalankan `node "/path/yang-dicetak/rollback.cjs"` untuk mengembalikan source. Rollback source tidak menghapus akun Auth/SQL yang telah dibuat; versi lama belum mendukung password UI baru. Data cloud tetap ada.

## Akun pertama dan laptop lain

1. Gunakan **browser dan alamat/origin yang masih menyimpan sesi pemilik ruang asli**. Jangan hapus site data/logout sebelum akun pertama aktif. Sesi pemilik yang sudah sah otomatis membuka **Pengaturan → Akun** setelah SQL terpasang.
2. Pilih profil Nando, masukkan username dan password minimal10 karakter, klik **Aktifkan**. Password tidak dicatat pada tabel aplikasi. Konfirmasi hanya setelah server selesai.
3. Di tab yang sama, pilih Hadist/Ryan atau Profil baru, isi username/password, klik **Buat akun**. Membuat nama profil saja pada tab Profil tidak membuat akun login.
4. Laptop lain cukup masuk dengan username/password yang dibuat tadi. Aplikasi mengambil workspace dan profil dari akun Supabase; tidak perlu undangan ruang atau membuat ruang baru. Semua editor ruang dapat mengedit proyek ruang itu. Untuk client luar gunakan link proyek lihat-saja.
5. **Pengaturan → Log out** mengakhiri sesi browser ini setelah perubahan tertunda berhasil disimpan. Bila simpan gagal, aplikasi tetap terbuka dengan error/draft. Browser mengingat login sampai Log out/sesi dicabut atau habis; website tidak mendeteksi restart PC secara andal.

Kalau browser sudah kehilangan sesi pemilik sebelum aktivasi pertama, jangan membuat ruang pengganti atau memakai identitas orang lain. Bootstrap perlu pemilik yang sah; identitas pemilik harus dipulihkan/dikonfirmasi dahulu. Tidak ada username/password default atau jalur publik untuk mengambil alih ruang.

Nama profil terikat akun saat login; tidak bisa berpindah menjadi pengguna lain melalui pemilih profil. Mengarsipkan profil akun anggota mencabut akses editor akun itu tanpa menghapus chat lama. Pemilik tetap mempunyai izin pengelolaan. Akun editor baru berbeda dari label profil; daftar akun otomatis dimuat ulang saat fokus dan setiap5detik ketika tab terbuka.

## Share dan navigasi

- Di Semua proyek, ikon Share berada di sebelah tiga titik. Link membuka **satu proyek**, tanpa login editor, **lihat saja**. Dapat dicabut/dirotasi dan mempunyai tanggal kedaluwarsa. Proyek lain, akun, chat serta History editor tidak ikut dibuka. Penerima tautan dapat melihat isinya selama tautan aktif. Link yang disalin dari localhost mengarah ke viewer Pages; publish frontend terbaru dahulu.
- User Flow: klik koneksi membuka opsi; klik kartu, tombol lain atau background menutupnya dan meneruskan aksi target. Drag kartu/kolom serta titik koneksi tetap berjalan. Judul kolom dapat diklik untuk rename. Trackpad dua jari untuk pan, Ctrl/Meta+wheel untuk zoom.
- Kartu Flow: ikon System UI di kiri bawah, Design UI di kanan bawah. Langsung membuka ID halaman itu. Tiga mode di toolbar mempertahankan halaman; kembali ke Flow memusatkan halaman aktif. Design UI pertama kali meminta aktivasi tabel design, lalu upload melekat ke ID System UI yang sama.
- Avatar aktif hanya orang lain, maksimal3 +N. Klik satu avatar melihat proyek, halaman, mode dan aktivitas orang itu; klik baris detail untuk mengikuti. Aktivitas adalah laporan aplikasi (lihat/edit/chat/presentasi), bukan perekaman ketikan/kursor.
- Perubahan data proyek memakai Supabase Autosaver500ms, Realtime dan pemeriksaan revisi berkala. Tidak perlu Save untuk mengirim edit normal. Snapshot bernama tetap melalui Simpan versi. Koneksi gagal tidak diberi status berhasil. Viewport/zoom/panel adalah preferensi perangkat.

## Validasi dan status online

67 pengujian Node/Auth SDK/domain/PostgreSQL dan suite DOM: aturan grants/RLS akun, pemblokiran anggota legacy setelah aktivasi, share satu proyek, replay SQL menjaga data, sesi diingat/local logout tanpa menyimpan password, provisioning UI error/retry dan pembersihan password, klik Flow/shortcut tepat halaman, avatar diri sendiri disembunyikan. Typecheck, lint, build lokal dan base `/blueprint-system/` lulus. Installer diuji pada empat baseline, alias package, no-op, penolakan source berubah, backup eksternal dan rollback byte-for-byte.

Uji langsung Supabase: dua sesi private Presence melihat lokasi satu sama lain; permintaan membuat akun dari non-owner ditolak403 tanpa membuat akun/profil. **Pembuatan akun/password dan login end-to-end online belum dapat diuji** karena SQL belum terpasang. Dua migration MCP gagal `Invalid or expired requestState`; pembacaan sesudahnya memastikan tabel `bp_accounts` belum ada. SQL manual wajib diselesaikan dahulu. Tidak ada klaim QA native Safari/HP.

Provision Auth dan registry DB melintasi dua layanan. Jika registry gagal, server mencoba menghapus hanya Auth user baru dari request itu; aktivasi pemilik dapat dicoba ulang dari sesi pemilik lama. Tidak ada jaminan transaksi atomik antar layanan. Advisors masih menandai definer RPC/policy legacy dan leaked-password protection nonaktif: [definer RPC](https://supabase.com/docs/guides/database/database-linter?lint=0029_authenticated_security_definer_function_executable), [anonymous policy](https://supabase.com/docs/guides/database/database-advisors?queryGroups=lint&lint=0012_auth_allow_anonymous_sign_ins), [password protection](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection). Pemeriksaan ini bukan sertifikasi keamanan menyeluruh.

## Publish Pages

Setelah dev dan SQL siap, Terminal baru dari folder proyek:

```bash
cd "$HOME/Desktop/0. Canvas UI-UX"
node scripts/push-github.cjs
```

Script memeriksa Git/source, menjalankan typecheck/lint/test/build dan push tanpa force. Lalu GitHub repository **Actions → Publish Blueprint to GitHub Pages → Run workflow → main**. Tunggu job deploy hijau. URL: https://nandomaul.github.io/blueprint-system/ . Runtime ini belum push/publish frontend karena tidak mempunyai kredensial Git Mac.
