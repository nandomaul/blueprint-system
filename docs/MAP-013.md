# MAP-013 — Satu ruang tim di semua komputer

Data proyek disimpan ke Supabase otomatis setelah berhenti mengedit sebentar. Pilihan Nando/Hadist/Ryan hanya penanda editor. Semua komputer harus bergabung melalui undangan ruang yang sama dan membuka proyek yang sama.

## Pasang dari Terminal VS Code

Simpan `blueprint-map-013-patch.cjs` di Downloads, lalu:

```bash
(
  set -e
  cd "$HOME/Desktop/0. Canvas UI-UX"
  node "$HOME/Downloads/blueprint-map-013-patch.cjs" --stop-dev
  npm ci --include=dev --bin-links=true
  npm run dev -- --open '/'
)
```

Source dipasang langsung ke root tersebut; tidak perlu memindahkan file per folder. Installer memeriksa baseline MAP-011/MAP-012, menjaga tambahan `scripts.deploy = npm run build`, dan menolak perubahan source yang tidak dikenali. Backup serta perintah rollback dicetak ke Terminal; backup berada di `~/Desktop/blueprint-checkpoints/MAP-013-...`. `--stop-dev` hanya menghentikan Vite port5174 yang terverifikasi berasal dari root ini. Data Supabase/proyek/History tidak direset.

## Hubungkan komputer lain

1. Pemilik ruang utama membuka **Pengaturan → Ruang tim → Salin tautan undangan**. Gunakan undangan ruang asli dengan ID `1e6615c9-4f88-4ebc-a448-5e4226d2d459`.
2. Buka undangan yang sama pada setiap komputer. Pilih profil lalu **Masuk**. Untuk dev, URL depan undangan memakai `http://127.0.0.1:5174/`; untuk situs online memakai alamat Pages yang sama dengan pengirim. Bagian `#join=...` tidak diubah.
3. ID kecil di Home/editor harus sama: `1e6615c9`. Hover memperlihatkan ID lengkap. Nama ruang yang sama saja belum cukup.
4. Buka proyek yang sama di dua komputer. Edit judul, teks, posisi, halaman, koneksi, brief, atau gambar. Sesudah **Tersimpan ke ruang tim**, perubahan diterima komputer lain melalui Realtime. Token polling3detik menjadi cadangan bila event terlewat; latensi tetap bergantung jaringan/server.

**Ruang baru** adalah ruang terpisah. Membuat profil baru tidak perlu membuat ruang baru. Link undangan adalah akses edit: bagikan hanya ke anggota tim. Link tidak ditanam ke source atau file publik.

Proyek yang sudah dibuat di ruang terpisah tetap ada. Jika perlu dipindahkan, download JSON/ZIP dari ruang asal lebih dahulu; impor JSON ke ruang utama membuat proyek baru dengan ID baru, sehingga rancangan yang sudah ada tidak tertimpa.

## SQL dan penyimpanan

Tidak ada SQL baru untuk MAP-013. Schema MAP-012 dan tabel Realtime telah diperiksa pada project `qjmwxezxtsuikywqoajj`.

Perubahan proyek, metadata proyek, profil/foto, History, gambar dan chat disimpan online melalui repository Supabase. Bahasa pilihan, profil aktif, zoom/pan/seleksi serta posisi panel adalah preferensi tampilan per perangkat; tidak menggeser viewport anggota lain. Cadangan browser hanya untuk pemulihan. Jika cadangan browser gagal, penyimpanan cloud tetap dicoba. Jika cloud gagal, status tetap **Belum terkirim**; download JSON sebelum menutup tab. Edit bertabrakan pada properti yang sama meminta penyelesaian konflik.

## Publish ke Pages

Setelah dev sudah sesuai, hentikan dev dengan Ctrl+C lalu:

```bash
cd "$HOME/Desktop/0. Canvas UI-UX"
node scripts/push-github.cjs
open "https://github.com/nandomaul/blueprint-system/actions/workflows/pages.yml"
```

Di GitHub pilih **Run workflow → main → Run workflow**. Tunggu job build dan deploy hijau, baru buka `https://nandomaul.github.io/blueprint-system/` dan pastikan revisi MAP-013. Settings → Pages → Source harus **GitHub Actions**. Script `npm run deploy` lokal yang berisi `npm run build` hanya membangun file; tidak mempublikasikan situs. Semua browser yang memakai situs lama perlu reload setelah deploy.

## Verifikasi

Typecheck, lint,61 tes Node/domain/SQL, UI DOM dan build diperiksa. Dua sesi autentikasi anonim independen telah diuji pada Supabase asli dalam workspace QA terpisah: autosave tanpa klik Save, pembaruan dua arah, merge edit berbeda, persist tombol/halaman/koneksi, serta akses nonanggota ditolak. Kanal raw WebSocket menerima payload perubahan database. Uji DOM juga mensimulasikan cadangan browser tidak tersedia dan retry setelah jaringan gagal. Uji ini bukan verifikasi visual native Safari/HP; total delay aktual bergantung koneksi.
