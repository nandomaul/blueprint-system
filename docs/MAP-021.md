# MAP-021 — Chat, riwayat, link dan stiker

Download `blueprint-map-021-patch.cjs` ke **Downloads**. Hentikan dev dengan Ctrl+C. Terminal VS Code dari **Desktop/0. Canvas UI-UX**, paste satu blok:

```bash
(
  set -e
  cd "$HOME/Desktop/0. Canvas UI-UX"
  node "$HOME/Downloads/blueprint-map-021-patch.cjs" --stop-dev
  npm ci --include=dev --bin-links=true
  npm run build
  npm run dev -- --open '/'
)
```

Node24. Installer menerima baseline011–020 yang sesuai; alias `deploy: npm run build` dipertahankan. Backup di luar root dicetak beserta perintah rollback. Jika source berbeda, berhenti tanpa menulis; jangan force atau mengedit hash.

## Perubahan yang terlihat

- Pesan dihapus: hanya penanda “Pesan dihapus” dan metadata pengirim/waktu. Mention, kartu System/Design/Flow, quote, stiker/gambar dan reminder tidak ditampilkan. Respons lama yang datang terlambat tidak menghidupkan isi pesan lagi.
- Link http/https/www bisa diklik. Teks biasa tetap teks; tidak ada embed HTML atau preview website yang mengirim request otomatis.
- Gambar gagal: placeholder per gambar dan Coba lagi; pesan lainnya tetap tampil. Retry koneksi mempertahankan riwayat yang sudah dimuat.
- Chat menampilkan50 pesan terbaru dahulu. Klik **Pesan sebelumnya** di bagian atas untuk riwayat lebih lama. Label memuat dibedakan dari percakapan kosong. Masing-masing origin tetap mengambil data dari akun/ruang Supabase yang sama.
- **Stiker → pilih → lihat draft → Kirim**. Tidak otomatis terkirim saat dipilih. Delapan label: **OK, NICE, GO IT, PLEASE, MAKE SURE, CHECK IT, HERE, +1**. “GO IT” mengikuti teks yang diminta. Gambar memakai robot baru yang sama pada setiap pose dan PNG transparan. Stiker tersimpan sebagai lampiran private melalui RPC lama, sehingga versi frontend sebelumnya tetap dapat membaca teks/gambarnya.

## Riwayat lama — cek tanpa menghapus

Source tidak dapat membuktikan isi database produksi. Tidak ada akses atau perubahan Supabase online dilakukan. Perbaikan ini tidak mereset tabel, ruang, akun, localStorage atau IndexedDB dan tidak memigrasikan chat menjadi penyimpanan lokal.

Untuk memastikan data lama masih ada, buka **Supabase project qjmwxezxtsuikywqoajj → SQL Editor → New query**. Paste seluruh isi **`supabase/manual/blueprint-chat-check-MAP-021.sql`**, lalu **Run**. File juga disediakan terpisah untuk download. Jangan paste installer CJS ke SQL Editor.

Hasil menunjukkan ID ruang, jumlah seluruh pesan/aktif/penanda hapus/catatan, tanggal pertama/terakhir, dan label pengirim. Tidak mengambil isi pesan/password, tidak menulis data. Bandingkan `workspace_id` dengan ID ruang di Settings pada localhost dan situs deploy. Jika jumlah>50, muat Pesan sebelumnya. Jika jumlah pesan ada tetapi UI kosong, kirim hasil hitungan dan error chat agar akses/pemuatan bisa ditinjau. Jika ada beberapa ruang, jangan membuat ruang baru untuk “memperbaiki” riwayat.

Pesan yang sudah dihapus secara sengaja sebelum revisi ini tidak dapat dipulihkan dari source; pemulihan isi yang benar-benar hilang memerlukan cadangan database. Query hitungan tidak mengarang/mengembalikan data dan tidak membuktikan seluruh isi pernah ada. Patch menjaga jalur pemuatan/penyajian yang dapat diperbaiki dari source.

**Tidak memerlukan migrasi SQL baru** untuk chat/link/stiker. SQL MAP017 yang aktif tetap digunakan. Semua file SQL sebelumnya dipertahankan byte-identik. Query021 hanya pemeriksaan opsional oleh pengguna.

## Stiker dan prompt

Dibuat dengan built-in imagegen, bukan CLI/API key pengguna. Prompt master: original friendly office robot, chamfered rectangular ivory head, no antenna, lavender side ears/gloves, dark plum visor, mint LED eyes/boots, coral diagonal pocket, clean cel shading, white die-cut outline, real transparent background; large exact label **OK**, OK-hand pose. Referensi karakter pengguna dipakai sebagai konteks robot ramah; desain baru tidak menyalin logo/antena/emblemnya. Master yang sama menjadi referensi identitas untuk tujuh generasi terpisah.

Pose/teks: **NICE** two thumbs up; **GO IT** energetic fist raised; **PLEASE** polite palms together; **MAKE SURE** clipboard/check and raised finger; **CHECK IT** magnifying glass/checklist; **HERE** pointing at location pin; **+1** one finger in agreement. Semua text/model sudah diperiksa.

File proyek disimpan di `public/stickers/v1/`. ZIP stiker terpisah membawa8PNG yang sama untuk pemakaian ulang. Tidak perlu menyalin satu per satu untuk aplikasi: installer menempatkan seluruhnya otomatis. File original generasi tetap disimpan terpisah; tidak ditimpa.

## Verifikasi, publish dan rollback

98 tes Node/domain/SDK/SQL lokal serta suite DOM lengkap, typecheck/lint/build lokal dan Pages. Tes riwayat memakai120+pesan, paging/retry gagal/reload, tidak kehilangan pesan tersimpan pada fixture. SQL berjalan dalam READ ONLY transaction PGlite; SDK memakai fetch tiruan. Ini bukan pemeriksaan database produksi atau visual Safari/HP.

Semua perangkat perlu frontend021 agar tampilan/penanganan error sama. Setelah cek lokal, publish memakai `node scripts/push-github.cjs`, lalu GitHub Actions → **Publish Blueprint to GitHub Pages → Run workflow → main**, tunggu build/deploy hijau. Installer tidak mem-push atau menerbitkan otomatis. Publikasi frontend tidak menjalankan SQL atau memindahkan percakapan.

Rollback: hentikan dev, jalankan `node '…/rollback.cjs'` persis dari output installer. Backup `~/Desktop/blueprint-checkpoints/MAP-021-…/` berada di luar root. Source/PNG dikembalikan byte-exact bila belum diubah; data online tidak di-reset. Bundle PDF/font masih mempunyai warning ukuran yang sudah ada.
