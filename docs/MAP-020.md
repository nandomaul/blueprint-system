# MAP-020 — Preview dan transisi perangkat

Simpan `blueprint-map-020-patch.cjs` ke **Downloads**. Terminal VS Code dari folder **Desktop/0. Canvas UI-UX**, tempel satu blok ini:

```bash
(
  set -e
  cd "$HOME/Desktop/0. Canvas UI-UX"
  node "$HOME/Downloads/blueprint-map-020-patch.cjs" --stop-dev
  npm ci --include=dev --bin-links=true
  npm run build
  npm run dev -- --open '/'
)
```

Gunakan Node24. Jika installer menolak source yang berbeda, jangan force/ubah hash; tidak ada source ditulis. `--stop-dev` hanya menghentikan Vite yang terverifikasi dari folder ini, bukan proses lain. Alias `deploy: npm run build` tetap dipertahankan; alias itu hanya build.

## Hasil yang bisa dicek

1. Buka proyek yang sudah mempunyai elemen System UI, aktifkan Design UI tanpa upload gambar, lalu **Preview**. Isi System UI tetap terlihat dengan keterangan singkat. Canvas Design UI yang sudah berisi gambar tetap tampil sebagai desain.
2. Di Preview, pindah ikon desktop ↔ smartphone. Frame dan elemen berubah ukuran/posisi dengan transisi360ms. Coba isi satu form; nilainya tetap saat berganti perangkat. Pada HP, mobile memakai lebar layar; frame HP dipakai pada desktop.
3. Jika Preferensi OS Reduce Motion aktif, pergantian langsung. Preview tidak menyimpan layout proyeksi, mengubah posisi canvas editor atau menulis database.
4. Halaman benar-benar kosong menampilkan keterangan. Jika render gagal, ada **Coba lagi → Detail error**. Editor tetap terbuka; jika masih gagal, kirim teks detail beserta nama halaman/perangkat. Jangan reset proyek atau Supabase.

Bug spesifik yang direproduksi: canvas Design UI kosong menutupi elemen System UI. Tidak ada log console dari browser pengguna pada lampiran terakhir; sebab lain yang spesifik perangkat belum dikonfirmasi.

## SQL — jalankan sendiri, hanya pemeriksaan

**Patch Preview ini tidak memerlukan migrasi database baru.** Semua SQL lama tetap ada. Lampiran SQL pengguna sama persis dengan `supabase/manual/blueprint-shared-MAP-017.sql`: tambahan chat/screenshot/reply/reminder, dengan prasyarat MAP012 dan015. Tidak menghapus tabel/kolom/proyek. Kebijakan lama tertentu diganti dengan kebijakan terikat akun; aksi hapus chat tetap soft delete khusus pengirim. Jumlah baris SQL lebih pendek tidak membuktikan data/schema lama terhapus.

File baru di root source: **`supabase/manual/blueprint-check-MAP-020.sql`**. File yang sama disediakan terpisah sebagai download.

1. Dashboard Supabase → pilih proyek **qjmwxezxtsuikywqoajj**.
2. Sidebar **SQL Editor → New query**.
3. Buka file `.sql` di VS Code, salin seluruh isinya ke SQL Editor, klik **Run**. Jangan tempel file `.cjs` di SQL Editor.
4. Query hanya SELECT metadata tabel/RLS, signature dan grant dasar RPC, kolom chat, publication Realtime dan bucket private. Tidak membaca isi chat/dokumen, tidak menulis data atau mengubah izin.
5. **OK** berarti struktur dasar ada; **MISSING/WARN** perlu ditinjau. Kirim baris hasil tersebut. Jangan jalankan ulang seluruh fondasi atau menghapus tabel untuk memperbaiki warning.

Query ini tidak membuktikan setiap data lama utuh, fungsi mempunyai body yang sama, policy benar untuk semua akun, Edge Function aktif, atau sinkronisasi dua laptop bekerja. Verifikasi akhir tetap memakai proyek/akun yang sama pada dua browser. Tidak ada akses Supabase online dilakukan oleh patch/AI.

## Verifikasi dan batas

94 tes Node/domain/SQL/SDK tiruan, suite interaksi DOM lengkap, typecheck/lint, build lokal dan base Pages. Tes baru mencakup canvas Design kosong, pergantian perangkat tanpa remount form, kesamaan data sebelum/sesudah preview, snapshot lama, error recovery, fallback modal, serta diagnostic SQL dalam READ ONLY transaction lokal. Semua tes SQL menggunakan PGlite/stub, bukan Supabase online.

Browser remote tidak dapat menjangkau server lokal dan protokol file ditolak; tidak dilakukan bypass. Tampilan animasi/native Safari/HP belum diverifikasi langsung. Build masih mempunyai peringatan ukuran bundle PDF/font yang sudah ada.

## Backup dan rollback

Installer mencetak path backup di luar root: `~/Desktop/blueprint-checkpoints/MAP-020-…/`. Hentikan dev dengan **Ctrl+C**, lalu jalankan perintah `node '…/rollback.cjs'` persis yang dicetak installer. Rollback mengembalikan byte source sebelumnya dengan pemeriksaan hash. Data Supabase/browser tidak di-reset; rollback source tidak mengembalikan data online.

## Deploy setelah Preview dicek

Publikasi ditahan sesuai pesan “sebentar” saat Preview bermasalah. Dari Mac, setelah hasil Preview sesuai, jalankan:

```bash
(
  set -e
  cd "$HOME/Desktop/0. Canvas UI-UX"
  node scripts/push-github.cjs
)
```

Helper memeriksa source, menjalankan pemeriksaan/build Pages, commit dan push ke main tanpa force. Repo **nandomaul/blueprint-system** → **Settings → Pages → Source: GitHub Actions**. Lalu **Actions → Publish Blueprint to GitHub Pages → Run workflow → main**. Source yang dipush belum otomatis publish karena workflow memakai dispatch manual. Tunggu job deploy hijau sebelum membuka situs. Jangan memakai `npm run deploy` sebagai bukti publikasi.
