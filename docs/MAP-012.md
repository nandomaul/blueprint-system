# MAP-012 — Workspace, profil dan chat

## Instalasi macOS

Unduh `blueprint-map-012-patch.cjs` dan `blueprint-shared-MAP-012.sql` ke Downloads. Buka Terminal VS Code:

```bash
(
  set -e
  cd "$HOME/Desktop/0. Canvas UI-UX"
  node "$HOME/Downloads/blueprint-map-012-patch.cjs" --stop-dev
  npm ci --include=dev --bin-links=true
  npm run dev -- --open '/'
)
```

URL: http://127.0.0.1:5174/. Footer menampilkan MAP-012. Installer memverifikasi seluruh source baseline dan membuat backup di `~/Desktop/blueprint-checkpoints/MAP-012-...`. Perintah rollback dicetak. Flag `--stop-dev` hanya menghentikan Vite port 5174 yang terbukti milik root ini. Port aplikasi lain ditolak. File yang berubah di luar baseline ditolak sebelum menimpa source. Installer tidak push/deploy.

## SQL

File `.sql` adalah SQL murni, tanpa kode Node. SQL ini membutuhkan fondasi Blueprint lama dan bisa dijalankan ulang. Jangan paste `.cjs` ke SQL Editor.

```bash
pbcopy < "$HOME/Downloads/blueprint-shared-MAP-012.sql"
```

Buka Supabase → project `qjmwxezxtsuikywqoajj` → SQL Editor → New query → Cmd+V → Run. SQL juga dipasang di `supabase/manual/blueprint-shared-MAP-012.sql`. Dokumen, versi, gambar, foto profil, chat dan cursor baca dipertahankan saat replay. Semua editor perlu source MAP-012 untuk fitur baru. SQL katalog lama tetap tersedia untuk pembaca lama.

## Yang berubah dan lokasinya

- Katalog: jumlah halaman kecil di bawah nama proyek; teks status Realtime disembunyikan (`src/components/ProjectHome.tsx`).
- Settings: tiga tab Profil/Ruang tim/Bahasa. Tiga profil bawaan muat tanpa scroll halaman; daftar panjang dan viewport pendek memakai scroll internal (`WorkspaceSettings.tsx`, `EditorProfiles.tsx`).
- Pencil profil: rename, foto raster maksimal input 4 MB, thumbnail 128 px, atau kembali ke inisial. Semua profil dapat diarsipkan ke Trash; minimal satu tetap aktif. ID bawaan N/H/R tidak dihapus. Restore memakai identitas yang sama. Chat dan History tidak ikut dihapus.
- Bahasa Indonesia/English langsung mengubah UI dan disimpan per browser. Isi proyek, nama, pesan dan data bisnis tidak diterjemahkan (`src/i18n.ts`, `src/locales/en.ts`).
- Manage project: checkbox tetap berada di baris, pencarian, pilihan format dan aksi bawah (`ProjectManager.tsx`).
- Download: PDF presentasi, JSON, ZIP, Dokumentasi PDF. Narasi aplikasi generik/corporate; keputusan/integrasi yang sudah ditulis tim tetap utuh.
- Ikon Manage Item = daftar periksa; daftar halaman = filmstrip; Blok = blok; Layer tetap layer.
- Chat/notes di panel kanan, tombol di header editor dan halaman proyek. Sesuai instruksi terakhir: pesan profil sendiri kiri, profil lain kanan. Pilihan nama adalah penanda aktivitas, bukan akun autentikasi baru.
- Mention profil melalui `@`. Referensi melalui ikon link: pilih proyek → System UI/Design UI/Alur/Brief → halaman. Label proyek dan halaman diambil server; klik membuka target yang sama. Target terhapus menampilkan error, bukan membuka halaman acak.
- Badge merah menghitung pesan profil lain yang belum dibaca. Cursor per sesi Supabase dan profil; pesan baru saat chat tertutup atau saat membaca pesan lama tetap belum dibaca. Pesan di tab Catatan tidak menandai pesan Chat yang tersembunyi. Stiker sengaja kosong.
- Riwayat memuat 50 pesan terakhir, tombol Pesan sebelumnya memuat batch lebih lama. Reconnect mengambil pesan yang tertinggal; idempotency mencegah kirim dobel ketika koneksi gagal.
- Adapter cloud: `src/services/cloudChat.ts`, state `src/hooks/useTeamChat.ts`, UI `src/components/TeamChat.tsx`. SQL baru di `supabase/migrations/*_blueprint_chat_profiles.sql`: RLS anggota ruang, cursor hanya milik sesi pemanggil, mutasi melalui RPC terjaga.

## Supabase dan aktivitas

Membuka aplikasi dan kembali ke tab memuat data cloud; refresh canonical yang sudah ada berjalan ketika aplikasi aktif. Tidak ada perubahan proyek untuk memalsukan aktivitas. Website tertutup/laptop tidur tidak dapat menjadwalkan request 3–5 hari secara andal. Free dapat dipause jika aktivitas rendah selama 7 hari; Supabase menyatakan Pro tidak dipause karena inaktivitas. Tidak mengubah paket berbayar atau memasang cron eksternal.

Sumber resmi: https://supabase.com/docs/guides/deployment/going-into-prod#availability

## Cek di laptop

1. Dua laptop memakai MAP-012 dan ID ruang yang sama.
2. Nando kirim chat, mention Hadist dan link Design UI halaman tertentu. Laptop Hadist menampilkan badge dan pesan, lalu klik link membuka halaman yang sama.
3. Tutup chat, kirim lagi dari laptop lain, badge naik. Buka Chat di posisi paling bawah, badge hilang. Scroll ke riwayat lama, pesan baru tidak melompatkan posisi baca.
4. Edit nama/foto profil dari settings, cek di laptop lain. Arsipkan lalu restore profil; chat lama tetap ada.
5. Ganti bahasa di Settings → Bahasa. Kembali ke canvas/project; konten dan ID proyek tetap sama.
6. Manage project: pilih sebagian atau semua, download PDF/JSON/ZIP, Trash memakai `systemdelete`, restore dari Trash.
