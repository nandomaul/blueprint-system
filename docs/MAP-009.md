# MAP-009 — tampilan clean, kontrol tetap bekerja

Root Mac: `~/Desktop/0. Canvas UI-UX`. Node 24. Dev `http://127.0.0.1:5174`. Installer menerima source MAP-005, MAP-006/RYAN-002, MAP-007 atau MAP-008 yang sesuai. Tidak push atau deploy.

## Pasang dari Terminal VS Code

Download `blueprint-map-009-patch.cjs`, simpan persis dengan nama itu di `~/Downloads`, lalu tempel seluruh blok berikut:

```bash
(
  set -e
  cd "$HOME/Desktop/0. Canvas UI-UX"
  node "$HOME/Downloads/blueprint-map-009-patch.cjs" --stop-dev
  npm ci --include=dev --bin-links=true
  npm run dev -- --open '/?template=ryan-002&view=design'
)
```

Installer menempatkan source dan CSS otomatis. Tidak perlu menimpa file satu-satu. Pemeriksaan hash menolak source yang berbeda sebelum penulisan. `--stop-dev` hanya menghentikan Vite port 5174 setelah PID, cwd dan command cocok dengan root proyek ini. Proses lain tidak dihentikan.

Backup pemasangan berada di `~/Desktop/blueprint-checkpoints/MAP-009-...`; Terminal mencetak lokasi dan perintah rollback lengkap. ZIP sebelum MAP-007 yang sudah diberikan tetap menjadi arsip terpisah. Backup source tidak mencakup data Supabase atau rancangan browser.

Saat ruang tim ready, URL membuka proyek Ryan yang sudah tersimpan di Desain. Edit tim, gambar dan History dipertahankan. Installer tidak menerapkan ulang seed di atas proyek yang sudah ada. Reload browser setelah server siap bila tampilan lama masih terbuka. GitHub Pages tidak ikut diperbarui oleh perintah ini.

## Yang berubah

Empat referensi pengguna 20 Oktober 2026 (075040, 075047, 075049 dan 075049-1) menjadi acuan untuk halaman masuk, daftar proyek, editor dan User Flow. Visual aplikasi memakai putih, abu lembut, aksen lavender, header satu baris, jarak dan ukuran kontrol konsisten. Isi rancangan tim tidak diganti dengan gambar referensi.

| Area | Cara memakai | Perilaku |
|---|---|---|
| Halaman masuk | Pilih N/H/R lalu Buat ruang atau Gabung | Pilihan editor dan kode undangan memakai alur ruang yang sama seperti sebelumnya. Input spasi kosong ditolak, kontrol dikunci saat proses koneksi. |
| Daftar proyek | Cari, urutkan, klik kartu atau menu tiga titik | Pencarian mengabaikan spasi pinggir; sort nama/tanggal bekerja. Menu membuka Desain atau Alur dari proyek yang dipilih. |
| Header editor | Arahkan pointer ke ikon | Tooltip menunjukkan Undo, Redo, History, Desain/Alur, brief, simpan versi, download, Preview, Presentasi, Bagikan dan profil. Semua fungsi lama tetap dapat diakses. |
| Nama proyek | Edit lalu Enter atau pindah fokus | Nama disimpan sekali setelah selesai. Escape membatalkan. Nama kosong kembali ke nama sebelumnya. Undo tidak dipenuhi setiap huruf nama. |
| Format di header | Web / Mobile / Presentasi | Mengubah layout **halaman aktif**. Bukan mengubah semua halaman sekaligus. Varian geometry, ID, target dan konten tetap memakai mekanisme MAP-007. |
| Rail mengambang kiri | Elemen, Teks, Upload, Layer, Halaman, Properti | Default panel tertutup supaya canvas lapang. Klik ikon untuk membuka panel. Posisi dock kiri/kanan atau floating tetap tersedia. |
| Kepala panel | Menu tiga titik, lipat, tutup atau drag | Kontrol dock dirapikan ke menu. Resize di tepi tetap bekerja. |
| Strip bawah seperti PPT | Klik thumbnail atau panah scroll | Strip tetap tersedia dan lebih tipis. Nama/nomor serta halaman aktif terlihat. Pembatas atas mengatur tinggi; toggle strip terpisah dari hide panel. |
| Zoom canvas | Slider, minus/plus, atau Fit | Zoom manual dipertahankan saat membuka/resize panel. Fit kembali mengikuti area kerja. Mengubah ukuran/format halaman menjalankan Fit agar desain tetap masuk layar. |
| Upload → drag gambar | Lepas di lokasi pada artboard | Komponen ditempatkan pada titik drop dengan koreksi zoom dan batas halaman, bukan selalu di tengah. |
| User Flow | Rail Langkah / Ikon / Detail; drag kepala panel | Panel dapat dipindahkan mengambang dan ditempelkan kembali ke kiri. Mengubah posisi panel tidak menulis perubahan ke proyek. Langkah, kolom, koneksi, ujung dan belokan tetap dapat diedit. |
| Zoom User Flow | Minus/plus atau seluruh peta | Titik grafik di tengah viewport tetap berada di tengah saat zoom, sehingga peta tidak meloncat ke sisi lain. |
| Fullscreen editor | Ikon kanan bawah | Menggunakan API fullscreen browser; bila tidak tersedia, informasi tampil dan pengguna dapat memakai fullscreen bawaan browser. Fullscreen Preview/Presentasi tetap tersedia. |

Status simpan dan koneksi memakai state sebenarnya. Avatar pada halaman masuk adalah pilihan editor, bukan klaim anggota sedang online. Informasi sukses ditutup otomatis setelah enam detik; error/konflik tetap terlihat. Draft, retry, History, Trash, ekspor PDF/JSON dan akses client tidak dihilangkan.

## Preferensi dan data

Layout lokal memakai `blueprint-editor-layout-v3`: panel awal tertutup, strip 88 px. Reset awal ini hanya susunan kontrol browser; rancangan dan cloud tidak berubah. Posisi panel User Flow juga preferensi browser. Profil → **Kembalikan layout ke dasar** mengembalikan susunan ini.

Tidak perlu SQL baru. Tidak ada perubahan dependency, schema JSON proyek, key, migration, RLS, Auth atau mekanisme sinkronisasi. Tidak ada cloud live write dari lingkungan pengembangan ini. Pilihan integrasi Lark/Feishu/WeChat tetap spesifikasi/rencana yang sudah ada; revisi visual tidak mengaktifkan transaksi HR.

## Pemeriksaan dan batas

Typecheck strict, lint dan 47 tes Node lulus, termasuk zoom center dengan batas minimum/maksimum. UI JSDOM memeriksa create/join/busy, cari/sort/menu proyek, commit nama proyek, drag gambar ke titik drop, zoom manual, panel flow tanpa write proyek, strip tetap tersedia, fullscreen API dengan mock, format bolak-balik, edit/simpan, Preview, History/Trash, PDF/JSON dan client 347 px. Build lokal/portable dan base Pages diperiksa tanpa publikasi. Installer diperiksa pada empat baseline, repeat no-op, backup/rollback, source mismatch dan simulasi port macOS.

JSDOM dan mock API tidak membuktikan tampilan piksel atau fullscreen native. Browser native Mac/Safari/touch dan dua laptop fisik belum diverifikasi. Browser pengujian tidak dapat membuka source lokal pada lingkungan ini; tidak ada klaim screenshot hasil browser. Referensi tidak diperlakukan sebagai screenshot aplikasi yang sudah terpasang.

Rollback source memakai perintah yang dicetak installer, setelah dev dihentikan. Rollback menolak source yang sudah diedit sesudah pemasangan. Rollback tidak menurunkan format data cloud; varian layout tetap perlu frontend MAP-007 atau lebih baru.
