## Pasang satu file

Simpan `blueprint-map-007-patch.cjs` di Downloads, buka Terminal baru VS Code, lalu paste:

```bash
(
  set -e
  cd "$HOME/Desktop/0. Canvas UI-UX"
  node "$HOME/Downloads/blueprint-map-007-patch.cjs" --stop-dev
  npm ci --include=dev --bin-links=true
  npm run dev -- --open '/?template=ryan-002&view=design'

```

| Bagian | Tindakan | Hasil |

Elemen mempunyai enam filter ikon satu baris. Rail tool bisa diurutkan dengan drag. Layer dan Properti dapat dibuka sebagai panel tersendiri. User Flow dipadatkan: ikon alat, tujuan pengguna, properti yang dapat dilipat, dropdown integrasi, pilihan PIC, serta preview di dekat tambah halaman. ## Penyimpanan dan batas format

- Geometry `web`, `mobile`, `presentation` disimpan bersama data proyek sebagai optional `design.layouts` dan `design.layoutMode`. Konten tetap satu sumber; mengganti teks atau target tombol tidak membuat salinan konten per perangkat.
- Sebelum varian perangkat pertama dibuat melalui editor, checkpoint `Sebelum layout perangkat · MAP-007` disimpan. Gagal checkpoint/simpan tetap terlihat sebagai error.
- Desain mobile awal diturunkan dari elemen yang ada menggunakan kelompok visual dan tata letak vertikal. Sesudahnya dapat diedit di canvas. Susunan arbitrer yang sangat kompleks tetap memerlukan penataan desain; halaman mobile otomatis dibatasi 4000 px. Bila terlalu panjang, aplikasi menampilkan pesan dan meminta pemisahan halaman.
- Client mobile menyembunyikan sidebar desktop, memakai pemilih halaman dan menampilkan layout mobile yang dapat dibaca. Proyeksi preview client tidak menulis ke rancangan atau mengganti izin. RLS / visitor / batas proyek dan pembatalan link tetap memakai mekanisme yang ada.
- PDF menampilkan layout aktif; JSON lengkap, termasuk geometry varian, tetap terlampir. Panel workspace dan preferensi browser tidak ikut data HR atau proyek.

## Supabase dan versi frontend

Project Supabase, URL/key, schema SQL dan aturan akses dipertahankan. Payload JSON yang sudah tersedia menerima geometry layout; pengujian SQL lokal dan SDK mengonfirmasi penyimpanan, merge dan pembacaan field tambahan. Tidak ada operasi cloud live pada revisi ini.

Gunakan MAP-007 pada semua editor dan frontend client yang membaca proyek dengan varian layout. Frontend lama memakai schema ketat dan tidak memahami field baru. GitHub Pages belum diperbarui; instruksi di atas hanya untuk dev.

## Backup / kembali

Installer membuat backup di `~/Desktop/blueprint-checkpoints/MAP-007-...`. Lokasi dan perintah `node '.../rollback.cjs'` dicetak saat selesai. Rollback menolak source yang sudah diedit setelah pemasangan. Source awal yang berbeda juga ditolak sebelum penulisan.

Hentikan dev sebelum rollback source. Rollback hanya source dan tidak menurunkan format data tim. Untuk data yang sudah mempunyai varian, tetap gunakan MAP-007 untuk membuka History / ekspor JSON; frontend lama tidak dapat membaca varian atau snapshot baru. Checkpoint sebelum konversi dapat dipulihkan menggunakan MAP-007. Jangan menghapus simpanan tim untuk memaksakan downgrade.

`--stop-dev` memeriksa PID, cwd dan command sebelum SIGTERM Vite pada root yang sama. Proses lain atau port ambigu tidak dihentikan.
