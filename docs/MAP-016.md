# MAP-016 — interaksi Flow, chat dan link halaman

Revisi ini memakai akun, ruang tim, Supabase Database, Realtime dan Storage yang sudah aktif. **Tidak ada SQL baru dan tidak perlu mengganti key atau password.** Data proyek, gambar, History dan Trash lama dipertahankan.

## 1. Pasang dari Terminal VS Code

Simpan **blueprint-map-016-patch.cjs** ke folder **Downloads**. Buka folder **Desktop → 0. Canvas UI-UX** di VS Code, pilih **Terminal → New Terminal**, lalu paste satu blok ini:

```bash
(
  set -e
  cd "$HOME/Desktop/0. Canvas UI-UX"
  node "$HOME/Downloads/blueprint-map-016-patch.cjs" --stop-dev
  npm ci --include=dev --bin-links=true
  npm run build
  npm run dev -- --open '/'
)
```

Buka `http://127.0.0.1:5174/`. Installer menulis file di tempat yang benar; tidak perlu menimpa `src/` satu per satu. `--stop-dev` hanya menghentikan Vite port5174 setelah folder prosesnya cocok dengan root ini. Proses lain tidak dihentikan. Gunakan Node24.x seperti konfigurasi proyek saat ini.

Installer menerima source terverifikasi MAP-011 sampai MAP-015, termasuk tambahan lokal `scripts.deploy = npm run build` yang sebelumnya sudah dipakai. `package.json` dipertahankan byte per byte. Panduan versi lama di `docs/` juga dipertahankan persis; MAP-016 hanya menambahkan panduannya sendiri. Pemeriksaan hash source aplikasi tetap berlaku. Jika source berbeda, installer berhenti sebelum menulis; kirim output error dan source terbaru, jangan memaksa overwrite.

## 3. URL per proyek dan tampilan

Alamat berubah otomatis ketika berpindah tampilan, halaman, Settings, chat atau preview. Salin URL dari address bar, atau **Share → Link halaman · login diperlukan**.

Contoh bentuk URL:

```text
https://nandomaul.github.io/blueprint-system/personnel~ID-PROYEK/design?page=ID-HALAMAN
https://nandomaul.github.io/blueprint-system/personnel~ID-PROYEK/userflow?page=ID-HALAMAN
https://nandomaul.github.io/blueprint-system/personnel~ID-PROYEK/system/settings?section=accounts
https://nandomaul.github.io/blueprint-system/settings?section=language
```

Nama proyek di depan ID membantu dibaca. ID tetap membedakan proyek bernama sama dan mempertahankan link ketika proyek di-rename. Bagian `page` menentukan halaman yang dibuka. URL localhost mempunyai struktur yang sama setelah `http://127.0.0.1:5174/`.

Link editor memerlukan login dan izin proyek yang sudah ada. Membagikan URL tidak menambah akses. Untuk client tanpa login, gunakan **Share proyek** yang membuat link anonim baca saja untuk satu proyek; link itu juga membawa tampilan/halaman yang sedang dibuka. Kode akses client tetap di fragment URL.

Login mempertahankan tujuan link. Back/Forward browser mengembalikan tampilan. Link bertingkat di GitHub Pages baru bisa dibuka langsung/reload setelah source MAP-016 **dan `public/404.html`** sudah diterbitkan.

## 5. Supabase dan sinkronisasi

MAP-016 tidak menambah tabel, policy, migration, fungsi server atau Auth account. Autosave tetap melalui cloud repository yang sama. Localhost dan Pages memakai Supabase yang sama ketika login memakai akun/ruang yang sama. Isi rancangan, upload, koneksi dan Trash adalah data bersama; viewport/pan/zoom, panel terbuka, pilihan halaman dan bahasa adalah preferensi tampilan perangkat.

Kalau Save menampilkan error, perubahan belum boleh dianggap tersimpan. Perubahan UI di paket ini tidak memperbaiki frontend publik yang masih versi lama sampai frontend tersebut dipublish. Pengujian nyata tiga sesi akun untuk posisi/gambar/Design UI telah lulus pada sesi sebelumnya; revisi16 menguji perubahan interaksinya melalui suite DOM, bukan mengklaim pengujian dua laptop native.

## 6. Backup dan rollback

Installer membuat folder baru di luar root:

```text
~/Desktop/blueprint-checkpoints/MAP-016-<waktu>-<acak>/
```

Di dalamnya ada `before/`, `after/`, `manifest.json` dan `rollback.cjs`. Terminal mencetak **path lengkap dan perintah rollback**. Untuk kembali: hentikan dev dengan Ctrl+C lalu jalankan perintah `node '.../rollback.cjs'` yang dicetak installer. Jika source telah diedit lagi, rollback berhenti untuk melindungi perubahan tersebut.

Rollback hanya mengembalikan file source. Tidak menghapus data browser atau menurunkan data Supabase. Sesudahnya jalankan `npm ci --include=dev --bin-links=true` lalu `npm run dev`.

## 7. Publikasi Pages setelah pemeriksaan lokal

Frontend MAP-016 belum dipush/deploy dari lingkungan ini karena tidak ada kredensial GitHub untuk menulis repo. Setelah lokal sesuai, gunakan Terminal baru dari root yang sama:

```bash
(
  set -e
  cd "$HOME/Desktop/0. Canvas UI-UX"
  node scripts/push-github.cjs
)
```

Script menjalankan pemeriksaan dan push source ke `nandomaul/blueprint-system` tanpa force push. Push ini belum menerbitkan Pages. Buka repo GitHub → **Actions → Publish Blueprint to GitHub Pages → Run workflow → main**. Tunggu job build dan deploy hijau. Setelah itu buka website dan reload. Semua laptop perlu frontend baru agar UI/rute yang tersedia sama.
