# MAP-019 — toolbar satu baris, drag presisi dan simulasi AI

## Pasang

Download **blueprint-map-019-patch.cjs** ke **Downloads**. Buka folder **Desktop → 0. Canvas UI-UX** di VS Code, kemudian **Terminal → New Terminal** dan paste:

```bash
(
  set -e
  cd "$HOME/Desktop/0. Canvas UI-UX"
  node "$HOME/Downloads/blueprint-map-019-patch.cjs" --stop-dev
  npm ci --include=dev --bin-links=true
  npm run build
  npm run dev -- --open '/'
)
```

Harus muncul **MAP-019 TERPASANG**, build sukses, lalu **http://127.0.0.1:5174/**. Semua file ditulis installer; tidak perlu menimpa satu per satu. Node24.x. package.json/lockfile dan alias lokal deploy tetap; `--stop-dev` hanya menghentikan Vite port5174 setelah folder proses cocok dengan target. Source berbeda ditolak tanpa force/penulisan parsial.

Paket belum dipasang di laptop dan belum deploy. ZIP unggahan Anda cocok dengan source MAP-015 (alias deploy tambahan), dijadikan acuan header lama; fitur terbaru tetap diteruskan dari MAP-018. Installer menerima source011–018 yang sudah diverifikasi, termasuk ZIP tersebut.

## Toolbar dan layout

- Toolbar atas **satu baris**: File/Edit/View/History, ikon Undo/Redo/History, System UI/Flow/Design UI, pilihan perangkat, Brief/Simpan/Download/Manage, AI/Chat/Preview/Share/Profil. Ikon tetap terpisah di luar menu. Pada layar sempit, geser toolbar **mendatar** untuk menjangkau sisanya; tidak berubah menjadi dua baris.
- Posisi dasar seluruh tool panel di **kiri**, dengan kepala panel sejajar rail. Klik Elemen/Teks/Upload/Layer/Halaman/Properti untuk membukanya. Tetap satu tool panel aktif.
- Layout baru memakai preferensi browser **v4**: pertama kali membuka versi ini mulai dari dasar kiri. Setelah dipindah/dock ke kanan atau floating, posisinya disimpan dan bertahan setelah reload. Ini pengaturan tampilan perangkat, bukan memindahkan panel semua anggota tim. Preferensi v3 lama tidak digunakan oleh versi19; tidak mengubah desain/proyek.
- Tarik kepala panel dari titik mana saja. Panel mengikuti titik yang dipegang, bukan melompat ke tengah. Grip toolbar properti, elemen/gambar, blok palette, rail panel dan palette Flow memakai titik pegangan yang sesuai; batas canvas tetap berlaku. Menu tiga titik panel tetap menyediakan kiri/mengambang/kanan.
- Saat chat atau AI dibuka, tool panel dan toolbar properti disembunyikan **sementara**. Canvas otomatis fit ke area tersisa. Klik tool di rail untuk menutup sidebar dan membuka tool tersebut; posisi dock sebelumnya dipertahankan. Menutup chat memulihkan panel. HP menampilkan chat satu layar penuh. Strip halaman bawah tetap ada.
- **View → Reset workspace** mengembalikan susunan dasar kiri; tidak mengubah dokumen.

## Simulasi AI dan demo

Klik ikon **spark / Asisten AI** di toolbar. Home juga mempunyai ikon kecil di kanan bawah. Preview menyediakan tombol Asisten AI dan FAQ proses pada informasi halaman.

| Fitur | Yang dapat dicoba sekarang |
| --- | --- |
| FAQ | Ketik pertanyaan, pilih contoh pertanyaan, lampirkan/paste screenshot lalu klik Tanya. Jawaban mengambil materi halaman/brief proyek aktif dan menampilkan sumber. Belum ada materi → memberi tahu bahwa jawaban belum tersedia. |
| Review Draft | Ubah nama, tanggal mulai/selesai dan isi draft contoh. Klik Review draft contoh, lihat temuan; Terapkan koreksi contoh memperbaiki typo contoh. Tanggal terbalik/invalid tetap perlu diperbaiki pengguna. |
| Klasifikasi | Upload gambar contoh atau isi deskripsi seperti “Kartu Keluarga karyawan”, lalu Kelompokkan contoh. Kategori didasarkan nama file/deskripsi; tanpa petunjuk masuk Perlu review. |
| Demo tanpa login | Pada halaman masuk klik **Coba demo**, atau buka **http://127.0.0.1:5174/?demo=personnel**. Navigasi alur contoh, kembali, ulangi, dan coba tab FAQ/Review Draft/Klasifikasi. |

Simulasi memakai aturan lokal; tidak memakai provider AI/OCR, tidak mempelajari isi gambar, dan tidak mengirim pertanyaan/gambar ke layanan eksternal. Lampiran ditinjau sebagai draft sebelum Tanya. Semua input assistant/draft contoh bersifat sementara; tidak mengubah desain, dokumen HR atau database. Warna/status “Simulasi AI” membedakannya dari layanan AI produksi.

Setelah frontend baru diterbitkan sendiri, link demo di Pages adalah **https://nandomaul.github.io/blueprint-system/?demo=personnel**. Website lama belum otomatis berubah oleh installer lokal.

## SQL, pengujian dan rollback

**Tidak ada SQL baru dan tidak ada Supabase yang diakses/diubah.** Installer tidak menjalankan SQL, mengubah password, membuat akun, atau deploy. Source SQL pada MAP-019 sama dengan MAP-018. Jika naik dari source yang lebih lama, file SQL versi sebelumnya dapat ikut ditempatkan di folder, tetapi tidak dijalankan installer. Jika nanti SQL perlu diterapkan, pengguna menjalankannya sendiri.

Lolos: typecheck, lint,89 tes Node/domain/SQL lokal/SDK mock, suite UI DOM, build lokal dan base Pages. Installer lolos baseline011–018 (paket asli dan alias deploy), source ZIP unggahan aktual, idempotensi, penolakan perubahan tidak dikenal tanpa menulis, serta rollback byte-identik. Pengujian baru memakai koordinat panel/workspace berbeda, pegangan dekat ujung kanan, penyimpanan posisi dock, penutupan panel sementara ketika chat, fit ulang, preview screenshot sebelum Tanya, koreksi draft, klasifikasi dan navigasi/ulang demo tanpa login. Tes SQL hanya fixture lokal. Native Safari/HP dan screenshot pixel browser belum diverifikasi langsung.

Backup otomatis: **Desktop/blueprint-checkpoints/MAP-019-<waktu>-<acak>/**, di luar root. Terminal mencetak perintah `node '/lokasi-backup/rollback.cjs'`. Hentikan dev dengan Ctrl+C sebelum rollback. Rollback source menolak edit baru yang tidak dikenal; tidak mengembalikan data cloud atau input yang sudah Anda simpan lewat aplikasi.
