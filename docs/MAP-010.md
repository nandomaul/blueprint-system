# MAP-010 — ruang bersama, pengelolaan dan Design UI

Root Mac: `~/Desktop/0. Canvas UI-UX`, Node 24, dev `http://127.0.0.1:5174/`. Tidak deploy.

## Instalasi satu kali

Simpan `blueprint-map-010-patch.cjs` di Downloads. Buka Terminal VS Code dan tempel:

```bash
(
  set -e
  cd "$HOME/Desktop/0. Canvas UI-UX"
  node "$HOME/Downloads/blueprint-map-010-patch.cjs" --stop-dev
  npm ci --include=dev --bin-links=true
  npm run dev -- --open '/'
)
```

Installer memeriksa source, membuat backup di `~/Desktop/blueprint-checkpoints/MAP-010-...`, lalu menempatkan seluruh file otomatis. `--stop-dev` hanya menghentikan Vite port 5174 dengan cwd dan command yang cocok. Source berbeda ditolak sebelum penulisan. Tidak menjalankan npm, SQL, push atau deploy sendiri.

Supabase proyek `qjmwxezxtsuikywqoajj` **sudah dimigrasikan pada sesi ini**. Tidak perlu menempel SQL atau installer ke SQL Editor. Catatan SQL ada di `supabase/migrations/20261020090306_blueprint_shared_management_design.sql` serta `supabase/migrations/20261020091404_blueprint_trashed_review_guard.sql`; docs ini menjelaskan pemakaiannya. Semua perangkat editor dan client harus memakai MAP-010 sebelum membaca data dengan profil/Design UI/Trash baru. GitHub Pages lama belum diperbarui. Untuk dev di HP, loopback `127.0.0.1` adalah HP sendiri; akses laptop melalui LAN hanya setelah menjalankan Vite dengan host LAN yang sesuai atau setelah deployment diminta.

Saat menghapus proyek, tautan client review aktif ikut dicabut; tab lama juga tidak dapat membuat atau merotasi tautan untuk proyek di Trash dan autosave ke proyek di Trash ditolak. Restore proyek tidak otomatis mengaktifkan tautan client lama; buat tautan baru dari Bagikan. Tidak ada hapus permanen di UI ini. History versi bernama tetap terpisah dari Trash proyek/item.

Shell aplikasi memakai satu viewport dan tidak membuat halaman luar bergulir. Daftar proyek, panel, dialog dan area kerja boleh bergulir di dalamnya. Pada layar pendek/zoom besar header membungkus, form entry dapat digulir di dalam area, dan canvas bisa digeser. Tidak menjanjikan seluruh isi daftar panjang muat sekaligus pada setiap zoom.

## SQL dan pemeriksaan

Migrasi menambah `bp_editor_profiles` serta `bp_document_settings`, RLS read anggota, public invoker RPC dan private guarded definer untuk mutasi. Keduanya masuk publication `supabase_realtime`; adapter mendengarkan empat tabel dan melakukan refresh kanonik 15 detik untuk event yang terlewat. Asset tetap privat dan diunduh dengan pemeriksaan hash. Konflik edit tidak ditimpa diam-diam.

Uji langsung Supabase memakai workspace/user sementara di dalam transaksi lalu ROLLBACK: dua anggota melihat profil/rename/pin sama, salah passcode ditolak, bulk gagal atomik, Trash menolak write, restore bekerja dan outsider tidak mendapat katalog. Sesudahnya tetap 1 ruang, 2 dokumen, 2 versi; hanya tiga profil dasar ruang lama yang di-seed oleh migrasi. Ini uji database, bukan dua laptop browser.

Advisor tidak melaporkan error akses baru. Peringatan tetap ada untuk anonymous-session membership dan RPC definer lama yang memang dipakai sistem undangan. Kebijakan tabel baru tetap memeriksa anggota; anonymous Auth berbeda dari role `anon` tanpa sesi. Catatan review:
[anonymous access](https://supabase.com/docs/guides/database/database-advisors?queryGroups=lint&lint=0012_auth_allow_anonymous_sign_ins), [definer RPC](https://supabase.com/docs/guides/database/database-linter?lint=0029_authenticated_security_definer_function_executable), [RLS tanpa policy pada tabel helper lama](https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy). Ada catatan performa index FK/policy lama: [index FK](https://supabase.com/docs/guides/database/database-linter?lint=0001_unindexed_foreign_keys), [policy ganda](https://supabase.com/docs/guides/database/database-linter?lint=0006_multiple_permissive_policies). Tidak mematikan proteksi hanya untuk menghilangkan peringatan.

Verifikasi: TypeScript strict, lint, 54 tes Node dan UI JSDOM; PDF dibaca/dirender dan ZIP diperiksa CRC serta navigasi JS-nya. Build lokal dan portable serta base Pages diperiksa tanpa deploy. JSDOM menguji event/state, bukan piksel/touch Safari asli. Fullscreen API pada tes dimock. Penempatan 100% di Mac dan sentuhan HP asli belum bisa dinyatakan terverifikasi dari environment ini.

## Backup dan rollback

Terminal mencetak perintah `node '/.../rollback.cjs'` dari backup di luar root. Hentikan dev sebelum rollback. Rollback menolak jika source telah diedit setelah pemasangan; tidak mengubah database/browser/gambar. Metadata SQL tetap ada agar tidak membuang simpanan tim. Data yang sudah memakai field MAP-010 atau profil baru memerlukan pembaca MAP-010; source lama tidak dijamin membaca JSON baru. Ekspor JSON/ZIP sebelum percobaan rollback, atau pasang ulang MAP-010 agar tetap dapat membukanya.
