# MAP-011 — Design UI gambar penuh dan panel dokumen

Root Mac: `~/Desktop/0. Canvas UI-UX`. Node 24. Dev `http://127.0.0.1:5174/`. Tidak deploy.

## Dua file unduhan

- `blueprint-map-011-patch.cjs`: installer source. Jalankan di Terminal, bukan SQL Editor.
- `blueprint-shared-MAP-011.sql`: SQL murni. Paste ke SQL Editor proyek Supabase `qjmwxezxtsuikywqoajj`, bukan ke Terminal sebagai kode shell.

Download keduanya ke `~/Downloads`, lalu tempel satu blok berikut di Terminal VS Code:

```bash
(
  set -e
  cd "$HOME/Desktop/0. Canvas UI-UX"
  node "$HOME/Downloads/blueprint-map-011-patch.cjs" --stop-dev
  npm ci --include=dev --bin-links=true
  pbcopy < "$HOME/Downloads/blueprint-shared-MAP-011.sql"
  npm run dev -- --open '/'
)
```

`pbcopy` menaruh SQL di clipboard Mac. Buka Supabase → pilih proyek tadi → SQL Editor → New query → Cmd+V → Run. Isi clipboard dimulai `-- BLUEPRINT MAP-011`, bukan `#!/usr/bin/env node`. Semua SQL dijalankan dalam transaksi; script memerlukan fondasi Blueprint yang sudah ada. Ia dapat dijalankan ulang dan tidak menghapus dokumen, gambar, history atau profil tambahan. SQL ini menyiapkan ulang katalog bersama/aturan akses yang sudah ada pada MAP-010; perbaikan layout tidak membutuhkan tabel baru. Sesi ini hanya memeriksa database online, tidak menjalankan ulang DDL online.

Installer memasang file otomatis, memeriksa hash source dan membuat backup di `~/Desktop/blueprint-checkpoints/MAP-011-...`. Perintah rollback lengkap dicetak di Terminal. Source berbeda ditolak sebelum penulisan. `--stop-dev` hanya menghentikan Vite port 5174 yang cwd dan command-nya cocok dengan root. Tidak upgrade paket, menjalankan SQL, push atau deploy.

## Arti zoom yang didukung

- Slider dan tombol zoom di footer, Cmd +/− atau Ctrl +/−, serta Ctrl/⌘ + wheel di area kerja mengubah **canvas saja**. Toolbar, rail, dialog dan strip tidak ikut di-scale oleh zoom canvas.
- Cmd/Ctrl + 0 melakukan Fit. Shortcut tidak mengambil alih ketika sedang mengetik atau dialog terbuka. Safari dapat mencadangkan shortcut tertentu; slider/footer tetap tersedia.
- Zoom browser lewat menu Safari / Chrome mengubah CSS pixel seluruh website. CSS tidak menjamin ukuran fisik toolbar sama pada semua skala browser; revisi ini tidak memasang kompensasi DPR atau mengklaim browser zoom terkunci. Untuk ukuran toolbar normal, pakai browser 100%, lalu zoom area kerja dengan kontrol aplikasi.
- Desktop dan mobile memakai shell satu viewport. Daftar, panel dan canvas tetap bisa digulir/geser di dalamnya. Mode tangan pada HP tetap ada. Native Safari/Mac/HP belum dapat diverifikasi dari environment ini.

## Pemeriksaan dan rollback

SQL diuji pada PostgreSQL lokal dari fondasi lama, lalu dijalankan ulang dua kali dengan dokumen, versi dan profil tambahan yang sudah disimpan. Token dokumen dan isi data tetap sama. Runtime UI memeriksa upload gambar penuh, thumbnail/preview, tujuan tombol, penghapusan/restore, pencarian/pilihan, tab Brief/Presentasi, zoom keyboard/wheel tanpa perubahan geometry/header, serta tiadanya success toast. Tes ini menggunakan JSDOM; bukan pengujian posisi piksel native.

Typecheck, lint, tes Node/UI, build portable, base Pages dan installer/rollback diperiksa. Tidak deploy. File PDF/ZIP yang dihasilkan memuat data rancangan; Trash ikut JSON/ZIP untuk pemulihan.

Backup hanya source. Rollback tidak mengubah database atau storage browser. Source lama tidak dijamin membaca data dari revisi yang lebih baru; simpan JSON/ZIP sebelum rollback. Perintah rollback menolak source yang sudah diedit setelah pemasangan agar tidak menimpa pekerjaan baru.
