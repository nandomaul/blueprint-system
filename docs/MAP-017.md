# MAP-017 — canvas, Flow dan chat

## Pasang sekali dari Terminal VS Code

Simpan **blueprint-map-017-patch.cjs** ke **Downloads**. Buka folder **Desktop → 0. Canvas UI-UX** di VS Code, lalu **Terminal → New Terminal** dan paste:

```bash
(
  set -e
  cd "$HOME/Desktop/0. Canvas UI-UX"
  node "$HOME/Downloads/blueprint-map-017-patch.cjs" --stop-dev
  npm ci --include=dev --bin-links=true
  npm run build
  npm run dev -- --open '/'
)
```

Awalnya muncul `MAP-017 TERPASANG`, kemudian build dan dev berjalan di `http://127.0.0.1:5174/`. Tidak perlu menimpa file satu per satu. Installer memakai Node24.x, mempertahankan package.json termasuk alias lokal deploy, dan hanya menghentikan Vite port5174 setelah folder prosesnya terverifikasi sama.

**SQL MAP-017 sudah dipasang pada project Supabase qjmwxezxtsuikywqoajj. Tidak perlu copas SQL lagi untuk project ini.** Akun/password dan ruang tim yang sudah ada tetap dipakai. File SQL cadangan ada di `supabase/manual/blueprint-shared-MAP-017.sql`; file CJS adalah installer Terminal, bukan SQL.

**Samakan frontend ke MAP-017 di semua perangkat sebelum mengedit bersama.** Warna/catatan Flow dan canvas visual baru menambah field data; frontend lama tidak mengenal format tambahannya. ## Canvas System UI dan Design UI

1. Pilih mode kursor di footer. Drag dari area kosong untuk membuat kotak seleksi. Aset yang bersinggungan dengan kotak langsung diberi highlight. Shift menambah/mengurangi pilihan ketika klik aset; Shift saat membuat kotak menambahkan hasilnya.
2. Drag salah satu aset terpilih untuk memindahkan seluruh pilihan dengan jarak antaraset tetap. Delete/Backspace memindahkan semua pilihan ke Trash. Saat kursor berada di kolom teks, tombol tetap menghapus teks.
3. Copy/Paste memakai **Ctrl+C / Ctrl+V** di Windows atau **⌘C / ⌘V** di Mac. Bisa lintas halaman; gambar dan target halaman ikut terbawa. ID elemen baru dibuat agar tidak bertabrakan. Ctrl/⌘A memilih semua; Ctrl/⌘D menduplikasi. Menu **Edit** menyediakan tindakan yang sama.
4. Resize melalui empat sudut dan empat sisi. Pilihan banyak aset mempunyai satu bingkai resize bersama; proporsi posisi relatif antaraset dipertahankan. Batas canvas tetap berlaku.
5. Grip titik-titik pada toolbar properti bisa ditarik. Lepaskan dekat kiri/kanan untuk dock; menu titik tiga juga menyediakan Atas/Kiri/Kanan. View → Reset workspace mengembalikan posisi dasar.
6. Panel Upload bisa dipindah/dock lewat kepala panel. Tinggi dan posisi floating dibatasi ruang editor; isinya bisa discroll tanpa tenggelam di bawah strip halaman.

Design UI kini memakai editor canvas yang sama. Upload desain satu halaman tetap tersedia di bar atas; Upload pada panel menambahkan referensi/aset yang bisa dipakai sebagai layer. Layout gambar Design UI disimpan terpisah dari komponen System UI. Membuka Design UI lama pertama kali menyiapkan canvas bersama dan menunggu penyimpanan sebelum editing dibuka. Menggeser gambar tidak menulis ulang logic System UI.

System UI tetap menyimpan alur proses dan target navigasi. Preview dan UI dalam ZIP menampilkan susunan visual terbaru dan tetap menjalankan target halaman. Thumbnail dan PDF mengikuti visual yang tersimpan. Copy gambar dan komponen yang memakai gambar mempertahankan datanya. Hapus layer/desain masuk Trash dan bisa dipulihkan melalui **File → Manage item → Trash → Restore**.

## User Flow

- Icon gambar berada di sebelah kanan pensil pada kartu. Icon mention di pojok kanan bawah membuka chat dengan proyek, halaman dan bagian Flow langsung terpilih. Referensi masuk draft; pesan tetap dikirim dengan Send/Enter.
- **Properti langkah → Warna penanda** memilih warna outline yang bernapas halus. **Catatan langkah** menyimpan note bersama dan dapat dibaca dari kartu/detail. Hapus penanda mengembalikan kartu biasa. Reduced motion menampilkan penanda statis.
- Garis memakai jalur ortogonal dengan sudut halus dan mencari jalan menghindari kartu lain. Ujung tetap bisa ditarik. Jika kartu benar-benar bertumpuk sehingga jalur tidak tersedia, muncul petunjuk untuk menggeser kartu; aplikasi tidak menggambar garis menembus isi kartu.

## Chat gambar, reply dan reminder

**Gambar/screenshot:** paste ke kolom chat atau klik icon gambar. Maksimal3 file PNG/JPEG/WebP, masing-masing4MB. Gambar tampil dalam draft beserta tombol buang; belum diupload/dikirim sebelum Send/Enter. Shift+Enter tetap baris baru. Kiriman gagal mempertahankan draft untuk dicoba lagi; retry memakai ID yang sama agar tidak menggandakan pesan.

**Titik tiga pada pesan:** Reply, Copy, Reminder/Undo reminder. Hapus pesan hanya tersedia untuk pesan sendiri dan diperiksa lagi oleh server berdasarkan akun pengirim. Reply menampilkan kutipan; pesan yang dihapus menjadi penanda, termasuk pada kutipannya.

**Tab Reminder:** daftar pesan yang ditandai tim. Status belum dibaca tersimpan per akun. Orang yang menandai tidak mendapat unread untuk tandanya sendiri. Membuka tab mengakui reminder yang dimuat; Undo reminder mengeluarkannya dari daftar bersama. Pesan lama bisa dibuka lewat paging. Badge chat atas juga memperhitungkan reminder belum dibaca.

Chat, upload yang sudah dikirim, penanda dan status baca memakai Supabase. Gambar chat disimpan di Storage privat yang sama dengan pembatasan anggota ruang; link client anonim tidak memberi akses chat. Thumbnail draft tetap di perangkat sampai dikirim. Riwayat chat tetap ada ketika profil diarsipkan.

## Backup dan rollback

Backup source otomatis berada di luar root: **Desktop → blueprint-checkpoints → MAP-017-<waktu>-<acak>**. Terminal mencetak lokasi lengkap dan perintah `node '.../rollback.cjs'`. Hentikan dev dengan Ctrl+C sebelum rollback. Installer menolak source yang berbeda dan tidak memakai force overwrite. Panduan versi sebelumnya tetap dipertahankan.

Rollback mengembalikan file source, bukan menghapus perubahan Supabase. Data yang sudah memakai field MAP-017 perlu dibuka dengan frontend MAP-017; jangan menimpa data tim dengan JSON lama untuk menyamakan versi. Ekspor JSON sebelum bereksperimen jika perlu salinan data sebelum perubahan.
