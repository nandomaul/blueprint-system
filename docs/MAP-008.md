## Pasang revisi pada folder aktif

Simpan `blueprint-map-008-patch.cjs` di `~/Downloads`. Buka Terminal baru di VS Code, lalu tempel seluruh blok:

```bash
(
  set -e
  cd "$HOME/Desktop/0. Canvas UI-UX"
  node "$HOME/Downloads/blueprint-map-008-patch.cjs" --stop-dev
  npm ci --include=dev --bin-links=true
  npm run dev -- --open '/?template=ryan-002&view=design'
)
```

Installer memeriksa hash source sebelum menulis. Bila Vite port 5174 berasal dari root yang sama, `--stop-dev` memeriksa PID/folder/command lalu mengirim SIGTERM. Proses lain tidak dihentikan. Backup source berada di `~/Desktop/blueprint-checkpoints/MAP-008-...`; perintah rollback lengkap dicetak di Terminal. Tidak perlu menyalin file `src/` satu per satu.

Setelah masuk ruang tim, proyek Ryan dibuka di Desain. Proyek yang sudah ada dibuka dengan edit tim saat ini. Tidak mengimpor ulang seed untuk menimpa proyek. ## Penyebab dan file yang diperbaiki

- MAP-007 mengganti `.canvas-editor` yang semula `height:100%` menjadi flex child, tetapi `.editor-body` masih block. Tinggi anak tidak mengikuti tinggi workspace; area yang membesar bisa terpotong oleh overflow shell dan mendorong footer di luar tampilan.
- `src/styles/app.css` kini menjadikan body editor flex container. `src/styles/workspace.css` memberi editor dua baris grid: canvas yang dapat menyusut dan footer halaman tersendiri. Footer tidak berada dalam panel dock atau area scroll artboard.
- `src/components/VisualEditor.tsx` memisahkan visibilitas panel dari strip, menambahkan caption/seleksi, auto scroll halaman aktif, dan rail kanan. `LibraryPreview.tsx` menampilkan contoh elemen; `ElementInspector.tsx` mengelompokkan properti tanpa menambah field data palsu.
- `src/domain/workspaceLayout.ts` menyimpan preferensi baru; `tests/workspaceUiHarness.tsx` memeriksa pemilihan/rename halaman, strip saat panel tersembunyi, edit properti tersimpan dan interaksi sebelumnya.
