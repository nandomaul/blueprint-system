# MAP-005 — Drag User Flow, elemen canvas dan client review

Project dan publishable key Supabase tetap sama. Fitur flow/elemen tersimpan pada JSON rancangan yang ada. Akses client memakai tambahan tabel, RPC dan RLS per proyek; bukan sekadar menyembunyikan tombol edit. Migrasi sudah diterapkan pada Supabase pengguna. Frontend belum dipush/deploy.

## Pemasangan satu blok

Simpan `blueprint-map-005-patch.cjs` di `~/Downloads`. Buka root `Desktop/0. Canvas UI-UX` di VS Code. Node 24.x diperlukan.

```bash
(
  set -e
  cd "$HOME/Desktop/0. Canvas UI-UX"
  node "$HOME/Downloads/blueprint-map-005-patch.cjs" --stop-dev
  npm ci --include=dev --bin-links=true
  npm run dev
)
```

Buka http://127.0.0.1:5174 dan refresh. Harus tertulis **MAP-005**. Semua laptop editor/client harus memakai revisi ini agar memahami jenis elemen dan kolom baru. Tidak perlu paste SQL atau mengganti URL/key Supabase.

`--stop-dev` memeriksa listener port 5174, working directory dan command proses. Hanya satu proses Vite dari root Blueprint yang sama boleh menerima SIGTERM. Tidak memakai killall atau SIGKILL. Jika port dipakai proses/proyek lain, patch berhenti tanpa menulis source. Tanpa opsi itu, hentikan dev melalui Ctrl+C pada Terminal dev terkait.

Patch kumulatif menerima baseline SUPA-001, MAP-003 atau MAP-004 yang identik dengan paket sebelumnya. Source yang sudah diubah akan ditolak sebelum ditimpa. Catatan README/PROJECT_STATE, file pribadi, .env, data browser dan data cloud tetap dijaga.

## Cara memakai User Flow

1. Buka proyek → **Alur**. Panel **Langkah** menyediakan Halaman, Mulai, Proses, Integrasi dan Hasil. Drag salah satunya ke posisi di peta. Klik tersedia sebagai alternatif.
2. **Hubungkan layar:** tarik titik sisi layar asal ke layar/titik tujuan. Alternatif keyboard/mouse sederhana: klik titik asal, lalu klik layar atau titik tujuan. Tombol navigasi benar-benar dibuat pada desain layar asal dan bisa dicoba di Preview.
3. **Pindahkan sambungan:** pilih garis, lalu tarik bulatan pada ujung asal atau tujuan ke layar lain. ID koneksi dipertahankan; tombol ikut berpindah/mengganti tujuan. Memindahkan asal juga memindahkan tombol terkait ke halaman asal baru.
4. **Atur garis:** pilih garis, tarik titik tengah untuk memindahkan belokan. **Rapikan garis** kembali ke jalur otomatis. Pilih Lanjutkan/Setujui/Tolak/Kembali/Kirim untuk nama aksi; nama khusus tetap tersedia bila diperlukan. **Putus koneksi** mengosongkan tujuan tombol tanpa menghapus tombol desain.
5. **Kolom/kelompok:** klik + Tahap baru / HR / Persetujuan / Selesai. Drag kepala kolom untuk memindahkan kolom beserta layar yang pusatnya berada di dalam kolom. Geser layar ke dalam/keluar kolom untuk mengelompokkan. Tarik sudut kolom untuk resize. Klik judul untuk mengganti nama. Hapus kolom mempertahankan layar di dalamnya. Maksimal 24 kolom.
6. **Ikon:** buka tab Ikon dan drag ke layar mana pun, atau klik untuk layar terpilih. Ikon langsung berubah dan ikut tersimpan.
7. **Properti:** tujuan pengguna tetap teks. Jenis langkah, output, PIC N/H/R/Tim, integrasi dan status memakai pilihan. Nama layar bisa diedit inline. Route langkah baru dibuat otomatis dari nama; route khusus lama dipertahankan. Route/output khusus/link referensi ada di Detail lanjutan.
8. Panel kiri bisa disembunyikan dan dibuka kembali lewat **Alat alur**. Peta tetap mendukung pan, zoom dan Fit.

Titik sambung kini interaktif. Garis yang dipindahkan tidak terputus dari perilaku tombol Preview. Integrasi Lark/Feishu/WeChat pada panel adalah spesifikasi/rencana atau simulasi; belum menghubungkan API produk HR.

## Elemen dan drag canvas

Ada **17 jenis komponen** dan total **24 pilihan pustaka**: judul, paragraf, tombol, input, kartu, gambar, tabel, checkbox, dropdown, textarea, ikon, persegi, lingkaran, garis, badge, avatar, progress, serta tujuh blok siap pakai (login, approval, navigasi, tabel karyawan, statistik, form karyawan, sidebar).

- Drag dari panel Elemen/Teks ke posisi canvas; klik tetap tersedia sebagai alternatif. Blok membuat beberapa komponen tersimpan yang dapat diedit satu per satu. Ukuran disesuaikan agar muat halaman mobile/web.
- Drag thumbnail Upload ke canvas untuk memakai gambar. Hapus gambar tetap membersihkan komponen aktif yang memakainya, tanpa menghapus snapshot lama.
- Semua objek canvas dapat dipindahkan dan di-resize dari sudut kanan bawah. Klik dua kali teks untuk mengetik. Toolbar/Posisi & ukuran menyimpan properti nyata.
- Drag item pada panel Layer ke item lain untuk mengubah urutan. Tombol ke depan/belakang tetap tersedia.
- Pilih tabel → **+ Kolom tabel** menambah kolom pada data tabel yang tersimpan.
- Pilih dropdown → Posisi & ukuran untuk mengisi daftar pilihan. Pilih progress untuk mengatur nilai. Pilih ikon untuk mengganti ikonnya.
- Pada Preview/client: checkbox, dropdown, input dan textarea dapat dicoba sebagai data sesi. Tombol menjalankan navigasi yang dipilih. Tidak ada transaksi HR yang dijalankan dari prototype.

Autosave/journal/merge, History, Restore, Trash, PDF dan JSON tetap digunakan. PDF menggambar jenis komponen baru, termasuk ikon vector; detail ukuran/layer/radius serta pengelompokan ada dalam JSON terlampir. Maksimal 100 komponen per halaman, 80 halaman dan 240 koneksi tetap berlaku.

## Client review yang dibatasi database

1. Editor buka proyek → **Bagikan → Client · lihat saja → Buat link review client**.
2. Pembuatan link menunggu perubahan terkirim. Tautan/kode memberi akses baca ke rancangan, brief dan seluruh referensi gambar proyek tersebut. Bagikan ke client yang dimaksud.
3. Client membuka link pada aplikasi revisi MAP-005. Tidak perlu password; sesi client dibuat terpisah dari sesi editor. Client tidak masuk `bp_members` dan tidak mendapat izin write RPC.
4. Client dapat mencoba navigasi aplikasi, melihat User Flow dan brief, masuk fullscreen, serta mengunduh PDF. Tidak mendapat History, daftar proyek lain atau alat edit. Kolom/garis tidak dapat dipindah dalam mode ini.
5. Client memeriksa versi tersimpan otomatis setiap 5 detik, juga saat tab aktif/koneksi kembali. Waktu pemeriksaan dan waktu versi ditampilkan. Ini polling data terbaru, bukan cursor/presence bersama atau klaim websocket langsung.
6. Link berlaku 30 hari. **Nonaktifkan** mencabut akses berikutnya. **Ganti link** mencabut kode dan sesi pengunjung sebelumnya; pengunjung harus membuka link baru. Salinan PDF/gambar yang sudah diunduh tentu tetap dimiliki penerima.

Pada dev lokal, URL localhost/127.0.0.1 menunjuk laptop penerima. Penerima perlu menjalankan aplikasi di laptopnya, lalu membuka link. Link publik yang bisa dibuka tanpa menjalankan dev baru tersedia setelah frontend dipublikasikan atas instruksi pengguna.

Akses editor tetap melalui undangan ruang tim. Jangan memberi undangan editor untuk client yang hanya perlu review. N/H/R tetap label editor, bukan identitas HR terverifikasi.

## Verifikasi dan batas

- Node24/Linux: typecheck, lint, **39 tes Node** termasuk 24 preset di tiga ukuran canvas, JSON, persistence/History, merge, PDF semua elemen, serta SQL viewer/editor/outsider.
- Tes UI JSDOM memakai event pointer/drop pada komponen aplikasi nyata: belokan, reconnect ujung, klik sambungan, tambah kolom, ganti/drop ikon, drop komponen, navigasi Preview, History, client read-only, refresh dan pencabutan akses. Ini bukan rendering browser/Safari.
- Database Supabase: migrasi diterapkan; transaksi rollback memverifikasi baca client, larangan write/share, SELECT RLS, tidak ada History, rotate/revoke dan versi tidak berubah. Fixture dibatalkan, bukan meninggalkan akun/ruang/link pengujian.
- Advisor: fungsi SECURITY DEFINER memang API yang memeriksa auth/membership/visitor aktif dengan search_path kosong; tabel invites/visitors sengaja tanpa akses langsung. Anonymous sign-in adalah sesi tanpa password yang tetap dibatasi RLS. Peringatan password protection tidak diubah karena alur ini tidak memakai password. Referensi: https://supabase.com/docs/guides/database/database-linter?lint=0029_authenticated_security_definer_function_executable dan https://supabase.com/docs/guides/database/database-advisors?queryGroups=lint&lint=0012_auth_allow_anonymous_sign_ins.
- Build lokal/portable dan base Pages diperiksa. Bundle masih besar karena font/PDF terbundel. Browser native, Safari drag/touch, fullscreen native, clipboard, websocket editor antar dua laptop dan visual responsive masih perlu diperiksa di perangkat pengguna. Tidak mengklaim 100% hanya dari JSDOM/build.
- Belum diterapkan di Mac pengguna, belum frontend deploy, belum user accepted. Backend HR/Lark/WeChat sebenarnya tidak dibangun di revisi ini.
