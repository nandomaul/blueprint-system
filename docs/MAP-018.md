# MAP-018 — toolbar, Flow dan brief

## Pasang di Mac

Download **blueprint-map-018-patch.cjs** ke **Downloads**. Buka folder **Desktop → 0. Canvas UI-UX** di VS Code, lalu **Terminal → New Terminal**. Paste satu blok ini:

```bash
(
  set -e
  cd "$HOME/Desktop/0. Canvas UI-UX"
  node "$HOME/Downloads/blueprint-map-018-patch.cjs" --stop-dev
  npm ci --include=dev --bin-links=true
  npm run build
  npm run dev -- --open '/'
)
```

Hasil awal harus `MAP-018 TERPASANG`, lalu build sukses dan dev membuka **http://127.0.0.1:5174/**. Gunakan Node24.x. Installer menempatkan semua file otomatis, tidak perlu timpa satu per satu. package.json/lockfile dan alias lokal `deploy: npm run build` dipertahankan. `--stop-dev` hanya menghentikan Vite port5174 yang working directory-nya sama dengan target. Source berbeda ditolak tanpa force/penulisan parsial.

Status paket: dibuat dan diuji di lingkungan pembuat; belum diterapkan di laptop dan belum diterbitkan ke GitHub Pages. Localhost dan web tetap memakai repository data bersama yang sama ketika frontend versi baru dipasang; tidak ada database lokal pengganti. Browser lain perlu frontend baru/reload untuk melihat perbaikan UI.

## Yang terlihat setelah dipasang

- **File, Edit, View, History** tetap tersedia. Ikon **Undo, Redo, History, Buka alur, Brief, Simpan versi, Download, Manage item** tersedia di luar menu juga. Menu dan tool dipisah menjadi dua baris desktop; grup dibungkus pada HP.
- Klik **Elemen**, lalu **Teks** atau **Upload**: panel sebelumnya tertutup. Ini berlaku walaupun sebelumnya floating. Posisi dock/ukuran tetap bisa diatur; **View → Reset workspace** kembali ke dasar. Panel ditutup semua saat reset; buka tool dari rail kiri.
- Preview contoh input/card/table tidak lagi membentuk gambar bertumpuk/dobel. Strip thumbnail halaman di bawah tetap ada.
- **Buka alur / Open flow** membuka Flow proyek aktif, bukan berpindah ke proyek contoh lain. Seluruh peta otomatis fit dan centered, termasuk kolom serta belokan di luar kartu. Fit ulang lewat tombol footer atau View → Fit canvas. Setelah pan/zoom, posisi pilihan pengguna dipertahankan.
- Judul, deskripsi, route dan tombol kartu mempunyai ruang terpisah. Teks panjang dipotong dengan ellipsis; tujuan lengkap tetap ada di detail/tooltip. Route tidak ditimpa tombol upload/mention.
- Garis otomatis menghindari kartu. Bagian jalur yang dipakai bersama digambar satu stroke dan panah identik tidak digandakan. Label hanya muncul di ruang yang cukup; jika koridor sempit, pilih koneksi untuk membaca label/detail. Ujung dan belokan tetap dapat ditarik.
- Badge **MAP-017** di Home dihapus. Revisi hanya tersimpan sebagai atribut internal `data-revision="MAP-018"` untuk pemeriksaan.

## Tambahkan delapan fitur ke proyek lama

1. Buka proyek yang ingin dilengkapi.
2. Klik ikon buku **Brief & data** → tab **Fitur**.
3. Periksa delapan kartu ADF-riends, lalu klik **Tambahkan ke brief** sekali.
4. Cakupan, Kriteria penerimaan, Struktur data dan Integrasi ditambah melalui autosave proyek biasa. Isi lama dipertahankan; tombol menjadi **Sudah di brief**. PDF/JSON/ZIP membawa brief terbaru lewat mekanisme ekspor yang sudah ada.

Template Personnel yang dibuat baru sudah berisi delapan fitur. Proyek bersama yang lama tidak diganti otomatis oleh installer. Jika bidang brief penuh melebihi batas, aplikasi menampilkan error; pendekkan bidang tersebut lalu ulangi.

Delapan fitur: FAQ AI dengan teks/gambar/knowledge proses; demo tanpa login; Superadmin; AI Review Draft; penyimpanan tanda tangan/stempel berizin; permintaan tanda tangan dengan persetujuan pemilik; smart-database dengan search/download/history; analitik dan klasifikasi AI dokumen KTP/KK. Ini spesifikasi aplikasi HR yang akan dibangun, bukan klaim konektor AI/approval produksi sudah aktif di Blueprint.

## SQL — dijalankan sendiri oleh pengguna

**MAP-018 tidak menambah tabel/kolom/RPC. Tidak perlu SQL baru untuk perubahan UI dan brief ini.** Tidak ada project Supabase yang diakses atau diubah dalam pengerjaan MAP-018.

File terpisah **blueprint-shared-MAP-017.sql** adalah SQL chat/gambar/reply/reminder versi sebelumnya, tidak diubah. Jika sudah terpasang, lewati. Jika belum:

1. Supabase Dashboard → project yang dipakai aplikasi → **SQL Editor → New query**.
2. Buka `supabase/manual/blueprint-shared-MAP-017.sql` di VS Code (atau file SQL unduhan).
3. Copy seluruh **isi SQL**, paste ke query, lalu **Run** sendiri. Fondasi schema Blueprint sebelumnya harus sudah ada.
4. Jika muncul error, kirim error lengkap; jangan ganti dengan reset/drop tabel. Script CJS installer hanya untuk Terminal, bukan SQL Editor.

Installer tidak mengeksekusi SQL, mengubah password, memasang migration ke cloud, atau melakukan deploy. Seluruh operasi Supabase manual tetap dilakukan pengguna.

## Pemeriksaan dan batasnya

Lolos typecheck, lint,85 tes domain/SQL lokal/SDK mock, seluruh suite UI DOM, serta build lokal dan Pages base. Installer lolos baseline011–017 (paket asli dan alias deploy), idempotensi, penolakan edit yang tidak dikenal tanpa penulisan, rantai installer015→016→017→018, dan rollback byte-identik. Tes baru meliputi fit kartu/kolom/jalur pada lebar280/390/1200/1800px, label tidak menabrak kartu/label lain, panah/stroke identik tidak berulang, panel floating lama dinormalisasi, klik tool menutup panel sebelumnya, ikon cepat bersama menu, dan delapan fitur tersimpan sekali tanpa mengubah ID/desain/aset. SQL lokal memakai fixture PGlite; tidak ada tes online Supabase.

DOM fixture bukan screenshot browser asli. Tampilan pixel dan gesture Safari/HP fisik perlu dicek pengguna setelah pemasangan. Tidak ada klaim native browser QA atau frontend sudah online.
